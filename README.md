# Python 101

Curso introductorio de Python en español, organizado en sesiones. Cada sesión trae un cuaderno de Jupyter, y varias incluyen un problemario y sus soluciones.

**Dirigido a:** Personas sin experiencia previa en programación.

## Sesiones

| Elemento | Descripción |
|---|---|
| `Python 101-1 Lo Básico/` | Lo básico; cuaderno, versión en Markdown y PDF, problemario y soluciones. |
| `Python 101-2 Sentecias Condicionales/` | Sentencias condicionales; cuaderno, problemas y soluciones. |
| `Python 101-2 Recursión/` | Recursión (sesión especial). |
| `Python 101-3 Cadenas/` | Cadenas de caracteres; cuaderno, problemario y soluciones. |
| `Python 101-4 For Loops/` | Ciclos `for`; cuaderno, versión corregida y ejercicios de media aritmética y mediana. |

## Cómo usar este material

1. Abre el cuaderno principal de cada sesión con Jupyter Notebook, JupyterLab, Visual Studio Code o Google Colab (subiendo el archivo).
2. Intenta primero el problemario de la sesión y compara después con las soluciones.
